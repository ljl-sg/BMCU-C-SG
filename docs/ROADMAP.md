## 1. 序列号命名规则 v2（✅ 2026-11-18 已实施）

**现行格式**

```
B 0 C │ 2 A C 7 D A 5 │ A 1 1 3 0
└标识┘ └─── UID 7 位 ──┘ └─配置5位─┘
例：B0C2AC7DA5A1130
```

- 前缀 `B0C`：BMCU 开源固件标识（`BMCU` 里的 `M`/`U` 不是十六进制字符，用 `0` 代替 `O`）
- UID 7 位 = 28 位（2.68 亿种），同机多台也不会重号
- 配置段放最后 5 位：问"这序列号什么意思"时只需报最后 5 位

**历史方案（已放弃）**

| 方案 | 未采用的原因 |
|---|---|
| `<槽位>…F<UID9>`（v1）| 无厂商标识，配置在前不便只报末尾 |
| `00600A + UID4 + 配置5`| 前缀与官方 AMS 相同，容易引起不必要的误会与麻烦 |

**回滚注意**：v1 与 v2 序列号不兼容，回滚固件时文档也要一并回滚。

## 4. 现场经验记录（实测得出，别再重复试错）

| 项 | 结论 | 备注 |
|---|---|---|
| **档位选择（本机 P2S）** | **本机不用 `high_force_load`**，用 `soft_load` 或 `standard` | **仅本机实测结论**；其他 P2S 用户可能适用 high_force，不作普适建议 |
| 静默指令重试参数 | `busSendMuteEx(ms, slot, 5, 1000)`（5 次 × 1000ms）| 间隔太密（120ms / 400ms）会导致 AMS 不真正掉线 |
| 序列号显示刷新 | 打印机缓存首次识别的序列号 | 换固件后若界面没变：打印机断电 → AMS 断电 → 打印机开机 → AMS 上电 |
| 多台 BMCU 刷写 | 逐台刷、逐台确认注册成功再刷下一台 | 一次全接上电容易抢同一槽位 |

> 这一节只记结论，完整过程见 `TEST-CHECKLIST.md`。
